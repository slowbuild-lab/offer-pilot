# 常见问题

## 页面打不开

核对6866/9527端口和 `/api/health`。后端健康不等于静态页面已构建，重新构建前端并复制后再生成运行包。不要同时开两个实例。

## 为什么仍显示旧界面

已有静态文件时Gradle可能跳过前端构建。在 `front/` 执行 `npm run build -- --webpack` 与 `node scripts/copy-dist.mjs`，再重新打包并启动新包。

## 新建空数据库为什么不行

程序仍依赖基础配置表与选项字典。当前仓库没有完整空库初始化包，需兼容模板；新账本的增量建表不替代完整基础库。不要删掉正在使用的数据库重试。

## 为什么一直等待

查看环境配置中的投递、全局、启动、休息及读取限制。等待不消耗投递名额；额外延迟、慢确认与全局排队会延长时间，180秒不是硬上限。

## 保护暂停如何恢复

先停止该平台任务，检查验证、登录和待核实岗位，再在环境配置勾选已检查并解除暂停。服务端最早允许时间未到时不能恢复，到时也不会自动恢复。

## 前程无忧为何暂停而不投

无法可靠对应岗位与勾选框、无法读取选中状态或无法确认单岗结果时都会暂停。该版本不再回退整页批量投递。

## 猎聘聊天窗口出现了却待核实

窗口出现或关闭不证明招呼已被接受；工具还要观察同岗位卡片状态变化。没有确认就保留UNKNOWN，不能直接按成功继续。

## 待核实能否自动重投

不能。点击超时不代表平台没有收到，记录和额度会保留。人工核实或解除暂停也不自动重发原岗位。

## 能否每天自动运行并发飞书

目前没有完整每日自动日轮，飞书业务通知也未接通。启动服务、确认方案都不会创建计划。

## 在哪里反馈

到[本仓库Issues](https://github.com/slowbuild-lab/offer-pilot/issues)，提供版本、系统、复现步骤与脱敏日志。不要提交Cookie、密钥、数据库或个人简历。
