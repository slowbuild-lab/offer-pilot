# 求职条件与投递保护

## 求职方案

BOSS/智联方案以版本草稿保存。只读预览采集候选后展示判断依据，确认应用后才供新任务使用；保存草稿不会替换当前生效版本。配置的改动不重写运行中的任务快照。

基础条件包括平台、关键词、城市、薪资与排除项；无法可靠核验的硬条件不会假装通过。旧平台黑名单可能继续参与，页面会说明来源。

## BOSS高级条件

公司白名单命中任一词即可。JD包含项命中任一词即可，排除项优先；条件启用却拿不到JD时跳过。按字面文本匹配，有有限否定例外，不是完整语义模型。

HR冷却期可选1–365天，留空不启用；同一HR换岗位也判断，身份无法识别时跳过。原因和上次接触依据会随预览/筛选结果展示。

## 四平台公共保护

环境配置里分别编辑平台和全局策略：

- 平台最小投递间隔120秒，附加0–60秒；全局新投递相隔至少30秒。
- 详情间隔10秒，翻页/关键词间隔30秒，启动缓冲15秒。
- 连续10岗或持续处理30分钟后休息15分钟。
- 平台每日20岗、全局40岗、详情200次/平台；预览及未匹配详情也计入。
- 同岗后续材料间隔5秒；自动列表加载另有每日50次上限。

这些是工具初始值。原额度更低时取低值，慢确认和排队可能延长等待，不保证180秒内一定继续。降低预算立即生效，提高预算次日生效；已有等待不因缩短设置而提前结束。

## 暂停与恢复

出现验证、登录过期、频控或不明确结果时暂停。先停止任务并在平台页面核实，再到环境配置勾选确认，解除保护暂停，最后手动启动。到达Retry-After时间也不会自行解除风险暂停。

智联成功弹窗关闭等待仍是独立配置，不是投递间隔。前程无忧/猎聘仍使用各自平台条件，不能把BOSS高级条件当作四平台规则。
