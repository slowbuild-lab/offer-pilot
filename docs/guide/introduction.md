# 项目介绍

求职领航是一个本机运行的求职任务管理工具，由本仓库维护者持续开发。它围绕“方案—预览—执行—核实”组织日常操作，减少重复操作，并保留可核对的结果。

## 当前能力

首页汇总平台状态、预算与待处理事项。BOSS/智联使用版本化方案与预览；BOSS进一步支持公司白名单、JD包含/排除、规则依据与可选HR冷却期。

四个平台分别持有浏览器资料与线程。默认可运行两个平台任务，实际外发仍通过公共节奏资格排队，不能理解为多个平台同时高速发送。

## 平台范围

- BOSS：方案、JD筛选、HR冷却、沟通/文字/图片动作记录。
- 智联：新版卡片与详情、滚动加载、任务额度、结果确认与核实。
- 前程无忧：可靠单岗关联及勾选状态成立时执行单岗提交；否则暂停。
- 猎聘：按当前卡片身份发起沟通，以同卡状态变化确认；不凭聊天窗口关闭推断成功。

统一方案不包含前程无忧与猎聘，当前作战台也未把拉勾列入支持范围。四平台执行链经过隔离验证，不代表全部真实页面变体持续可用。

## 组成

`front/`提供Next.js/React管理界面；Java 21与Spring Boot提供接口、账本和任务控制；Playwright客户端与浏览器驱动执行平台操作；SQLite记录本机配置和结果。

默认管理端口6866、后端9527。数据库、浏览器资料和简历仅保留在本机。技术版本以项目构建文件与锁文件为准。

## 后续工作

每日计划、飞书通知与完整无人值守恢复仍是后续规划。旧AI/机器人配置入口存在，不代表已接入统一方案或当前任务通知。
