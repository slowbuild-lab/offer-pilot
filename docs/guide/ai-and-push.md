# 模型与通知能力边界

## 模型配置

旧BOSS路径保留模型接口、技能介绍和提示词等配置入口。密钥仅在本机环境配置中填写，不要写进仓库或反馈日志。使用外部模型会按所选服务产生费用，本项目不提供成本保证。

当前统一方案会关闭旧BOSS AI及重复沟通设置，因此旧页面开关不等于已确认方案中的行为。不要据此认为每个任务都会自动生成或发送模型内容。

## 图片材料

BOSS图片材料使用当前页面提供的材料流程，确认后才供对应方案使用。不要把个人简历放进源码资源目录、公开截图或构建附件中。

## 通知状态

环境配置保留企业微信机器人相关字段与旧代码，但不能把配置存在当作任务通知已接通。飞书业务通知仍未完成。

当前异常至少在页面显示，用户需要查看平台窗口完成登录或验证。每日自动计划、日报及无人值守恢复尚未交付，不应按“已经接通”来使用。

未来通知能力应明确事件、发送失败、重试与人工恢复语义；本页不作即将完成的时间承诺。
