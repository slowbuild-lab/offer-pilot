# BOSS 首批筛选功能交付与验收

日期：2026-10-28。范围：公司白名单、工作内容包含/排除、筛选原因与命中原文。仅 BOSS 生效。

## 已交付

- **求职方案 → BOSS 高级筛选**：每行一项，公司名命中任一白名单词即满足；工作内容包含项命中任一词即可，排除项优先。留空不限制。未选 BOSS 时不能保存非空 BOSS 条件。
- **解释依据**：预览显示通过/排除原因，可展开原文并高亮命中词；平台原有黑名单和活跃过滤原因也会说明来源。普通文本按字面匹配，支持有限明确否定例外，不属于完整语义分析。启用工作内容条件但缺少详情时跳过。
- **投递记录与额度 → BOSS 候选筛选记录**：支持北京日期、结果筛选与分页，独立展示筛选结论。规则通过不代表已投递，筛选记录不占额度。同一任务同一岗位不重复累计。
- **执行接入**：采集岗位真实详情后使用统一规则评估，在沟通前判定。筛选记录保存失败时阻止后续外发，原账本、额度、停止和未知结果保护继续保留。

## 如何测试

1. 打开 [求职方案](http://127.0.0.1:6866/job-profile)，选择 BOSS，填写高级条件，点击“保存为新草稿”。
2. 点击“只读预览”，展开筛选依据，核对命中原文与排除原因。保存草稿不会直接替换当前生效版本。
3. 核对后再“确认并应用此版本”。后续任务按确认版本执行。
4. 打开 [投递记录与额度](http://127.0.0.1:6866/delivery-records)，查看“BOSS 候选筛选记录”。该区域记录实际任务评估；只读预览不会伪造任务记录，暂无记录时为空是正常现象。
