## 接口补充

`GET /api/delivery/records?platform=boss&page=1&from=2026-10-20&to=2026-10-26&state=UNKNOWN`

`from/to/state` 可选；无日期仍兼容查询全部历史。返回原有 `items/page`，新增 `pageSize/total/hasNext`。状态按平台白名单校验；日期格式、真实日期和先后顺序均校验，不静默放宽条件。查询使用参数化 SQL 和同一只读事务快照，无数据库迁移。

`GET /api/workbench/summary` 新增 `delivery` 两平台摘要，`recent` 每条增加 `platform`。`today.unknownCount` 为两平台历史待核实总和，任何账本不可读时返回 null。最近任务不可读时以 `recentError` 标记；不能以空列表解释成没有历史。
